Quick Help Guide

Understanding the Symbols:

  • ✔️: 1/3 sets agree on "Yes";

  • ✔️: 2/3 sets agree on "Yes";

  • ✔️: Full agreement on "Yes";

  • ❔: Unknown / Not Classified / Not Applicable;

  • ⚠️: Conflict (sets disagree Yes/No);

  • ❌: 1/3 sets agree on "No";

  • ❌: 2/3 sets agree on "No";

  • ❌: Full agreement on "No";

  • 👤: Last changed or verified by the user;

  • 🖥️: Last changed or verified by AI Model;

  • 📕: A PDF is attached to this paper;

  • 📗: An annotated PDF is attached to this paper;

  • 💰: The PDF for this paper is paywalled

  • 📄: This is a Journal paper

  • 📚: This is a Conference paper

How to Use:

Filter Papers: Use the year range, minimum page count, and the search bar at the top. Press "Apply" (appears on change) for server-side filters.

Checkbox filters: Use checkboxes like "Hide Offtopic", "Hide X-Ray", or "Only Survey" for quick client-side filtering. As the checkboxes have no permanent labels, hover each checkbox to identify the purpose for each. Survey, THT, SMT, and Dataset checkboxes cycle through three states (All → Only Yes → Only No) using standard checked, unchecked, and indeterminate visuals.

Certainty Indicators: Classification results are averaged across three independent runs. Emojis with partial translucency indicate partial agreement (33% or 66% opacity). A ⚠️ warning icon appears when runs directly conflict (e.g., two "Yes" vs one "No"). Fully solid emojis mean all three runs agree completely.

Classify/Verify: Click the "Classify this paper" or "Verify this paper" button in the detail row to run LLM-based classification on a single paper. Use the top buttons in the "Batch Actions" menu to classify or verifyremaining or all papers.

Edit Data: Click on any ✔️ ❌ ❔ symbol in the main table to cycle its value (this is automatically saved on change). Click 'show' in the details column to edit text fields (like "Model Name" or "Other Defects"). These have to be saved manually by clicking on "Save Changes". A paper can be marked as paywalled by including "paywalled" in the user comment Unavailable inside HTML exports.

Tracking User Edits: The "User Changes" column displays a count of fields you have manually overridden compared to the last LLM classification, helping you quickly identify papers that may need re-evaluation.

Search: Type on the search bar for instant search on all relevant fields. User comments are searchable. Classifier/Verifier traces are not (to avoid false-positives/noise)

View Statistics: Click the "View Statistics" button to see charts and lists of repeating journals, authors, keywords, and mentioned features/models as well as relevant charts. The stats are calculated based on currently visible filtered data.

History & Classification Sets: Opening a paper's history reveals four vertical tabs. The Main tab shows the averaged consensus, certainty overlays, and user edits. The Set 1, Set 2, and Set 3 tabs display the raw, individual logs for each of the three parallel classification runs, allowing you to inspect exactly where disagreements occurred.

Export and Backup: Use the "Export HTML" or "Export XLSX" buttons inside the "Export & Backup" menu to download the currently filtered dataset, or use the backup / restore buttons to work woith full *.parça.zst backups. Backups include the database, original and annotated PDFs, HTML export and a XLSX spreadsheet. Unavailable inside HTML exports.

Import Data: Use the "Import BibTeX" button to add new papers to the database from a .bib file. Unavailable inside HTML exports.

Attach PDF: Click on the ❔ in the PDF column of a paper to upload a PDF to it. Unavailable inside HTML exports.

Read/Annotate PDF: Click on the 📕 or 📗 of an existing PDF to open the integrated PDF.js annotator. All annotations are autosaved after 5 seconds. The annotated status only changes from 📕 to 📗 after a page reload. This doesn't affect annotation saving. For the HTML export, the PDF is loaded directly (read-only) on the user's default reader instead. This requires the PDF to be in the correct folder structure, as obtained from a full backup.

State Preservation: Your active filters, sorting preferences, and which detail or history rows are expanded are automatically preserved in the browser's URL. This allows you to bookmark or share a specific view of the table, which will restore exactly as you left it upon reload.

Tip: The table is pre-sorted to show papers with user comments first. You can click any column header to sort by that field.

About

ResearchParsa

ReseachParsa - PCB Inspection Papers Database Browser.

Developed by Luis Alfredo da Silva, to assist his own Master's degree research at Universidade do Estado de Santa Catarina (UDESC).

The following open source libraries, and its dependencies, are leveraged by this software:

Backend: Python, Flask, SQLite3

Frontend: HTML5, CSS3, Vanilla JS

Data Visualization: Chart.js

PDF View/Annotation/Autosave: PDF.js

Utilities: rcssmin, rjsmin (minification), openpyxl (Excel export), pako (compressed HTML export), Zstandard (backup/restore).

Classification and verification was inferenced by Unsloth's Dynamic quants of Qwen3-30B-A3B-Thinking-2507 model from Qwen/Alibaba Cloud.

Local Inference engine: vLLM.

Original papers data (BibTeX) was sourced from Scopus, IEEE Xplore (some) and ACM Digital Library

Original search query (Scopus format): TITLE-ABS-KEY(( "printed circuit*" OR "Circuit board*" OR pcb OR pcba ) AND ( inspection OR manufactur* OR assembly OR defect* OR solder* OR weld* OR "Automat* optical" )) AND PUBYEAR > 1973 AND PUBYEAR < 2027 AND ( LIMIT-TO ( DOCTYPE,"ar" ) OR LIMIT-TO ( DOCTYPE,"cp" ) OR LIMIT-TO ( DOCTYPE,"re" ) ) AND ( LIMIT-TO ( PUBSTAGE,"final" ) )
